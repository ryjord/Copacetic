# Support

## Getting help

Choose **Help > Send feedback** in Copacetic. It opens your email program with a
message to contact@mrenigma.uk, with Copacetic's version, your operating system
and its architecture already filled in, so a problem can be reproduced. Nothing
is sent until you press send.

Without the app to hand, write to contact@mrenigma.uk directly and say which
version you have (Settings > About) and on which system.

A security problem should not go in an ordinary message: SECURITY.md says
where to report it privately, what to include and what happens next.

## What helps

- What you did, what you expected, and what happened instead.
- The address of the page, if a site is involved and you are happy to share it.
- The diagnostics log, from Settings > About > Diagnostics log. It never names
  a page you visited, but read it before you attach it.

## Before you write

- **A site does not work.** Open the connection details from the left of the
  address bar and choose Allow on this site. If that fixes it, say which site,
  since the filter lists can be told.
- **Passwords cannot be read after an update on macOS.** Builds are not yet
  signed, so macOS can refuse an updated Copacetic the keychain key. Nothing is
  deleted; importing your last export brings them back.
- **macOS says Copacetic cannot be opened.** The builds are not signed yet;
  the README's install section says how to open it the first time.

## Which versions are supported

The most recent release, as SECURITY.md says. A fix comes in a new version
rather than a patch to an older one; update from Settings > Updates.
